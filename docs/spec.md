# ミッションボード 詳細仕様書 v2.0

## 1. プロジェクト概要

**アプリ名：ミッションボード**
親子で使うタスク・ルーティン管理アプリ。ADHD気質のある子ども・大人がやるべきことを逃さず、楽しく達成できることをゴールとする。

---

## 2. タスク管理仕様

### タスク種別

**ルーティンタスク（定期）**
- 繰り返しパターン：毎日（`daily`）/ 曜日指定（`weekly:0,1,2`）/ 毎月（`monthly:15`）/ カスタム（`custom`）
- 実行時間帯：朝・昼・夕方・夜・就寝前のブロックで指定

**突発タスク（スポット）**
- 期日指定あり／なし
- 親が子どもに割り当て可能

### 時間帯ブロックと通知時刻

| time_block | 通知時刻（タスク開始15分前） |
|------------|--------------------------|
| morning（朝） | 7:30 |
| afternoon（昼） | 15:00 |
| evening（夕方） | 17:00 |
| night（夜） | 19:00 |
| bedtime（就寝前） | 21:00 |

### 子どもによるタスク作成

子どもも自分のタスクを作成・提案できる。親の承認後に有効になる。

| ステータス | 説明 |
|---|---|
| pending | 子どもが作成・親の承認待ち |
| approved | 親が承認・ミッション一覧に追加 |
| rejected | 親が却下 |

- 1日の提案上限：5件
- ポイント値は親が承認時に設定

---

## 3. ADHD対応の工夫

- **時間帯ブロック制**：「〇時に何をする」ではなく「朝のミッション」のようなブロック管理
- **タスクの細分化**：大きなタスクを小さなステップに分解して登録
- **段階的リマインダー**：時間帯開始15分前に通知
- **即時フィードバック**：完了ボタンを押した瞬間の紙吹雪アニメーションで報酬を即時に与える
- **ストリークの可視化**：連続日数を炎アイコンで表示

---

## 4. 通知種別

| 種別 | タイミング | 受取人 |
|---|---|---|
| reminder | 時間帯開始の15分前 | 子ども |
| followup | 未完了時のフォローアップ | 子ども・親 |
| approval | 子どもが完了報告した直後 | 親 |
| proposal | 子どもが提案を送った直後 | 親 |
| result | 親が承認・却下した直後 | 子ども |
| summary | 就寝前（毎日0時に生成） | 親 |
| streak | 連続達成時 | 子ども |

通知は Google Apps Script（`gas/trigger.gs`）が5分ごとに `notifications` シートを監視し、時刻が来たものを FCM 経由で送信する。

## 5. ゲーミフィケーション

### バッジ設計

| badge_type | アイコン | 表示名 | 獲得条件 |
|---|---|---|---|
| first_mission | 🌟 | はじめてのミッション | 初めてタスクを完了 |
| streak_3 | 🔥 | 3にちれんぞく | 3日連続でルーティン完了 |
| streak_7 | ⚡ | 1しゅうかんれんぞく | 7日連続でルーティン完了 |
| streak_14 | 🧱 | 2しゅうかんれんぞく | 14日連続でルーティン完了 |
| streak_30 | 💎 | 1かげつれんぞく | 30日連続でルーティン完了 |

バッジは `badges` シートに記録され、同じ `badge_type` は重複付与されない。

※ `points_10` / `points_50` / `points_100` は過去互換のため badge_type 名を維持しており、実際の閾値はそれぞれ 20 / 80 / 150pt。

### ポイントシステム
- 各タスクに `point_value`（1〜5）を設定
- タスク完了時に `task_logs.points_earned` に記録
- 累計ポイントは `task_logs` の合算で計算

### ご褒美交換
- 親がご褒美内容とポイントコストを設定（`rewards` シート）
- 子どもがポイントを使って申請 → 親が承認
- ステータス：`active`（有効）→ `redeemed`（交換済み）
