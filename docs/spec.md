# ミッションボード 詳細仕様書 v1.1

## 1. プロジェクト概要

**アプリ名：ミッションボード**
親子で使うタスク・ルーティン管理アプリ。ADHD気質のある子ども・大人がやるべきことを逃さず、楽しく達成できることをゴールとする。

---

## 2. タスク管理仕様

### タスク種別

**ルーティンタスク（定期）**
- 繰り返しパターン：毎日 / 曜日指定 / 毎週 / 毎月
- 実行時間帯：朝・昼・夕方・夜・就寝前のブロックで指定

**突発タスク（スポット）**
- 期日指定あり／なし
- 親が子どもに割り当て可能

### 子どもによるタスク作成

子どもも自分のタスクを作成・提案できる。親の承認後に有効になる。

| ステータス | 説明 |
|---|---|
| pending | 子どもが作成・親の承認待ち |
| approved | 親が承認・ミッション一覧に追加 |
| rejected | 親が却下・理由コメント可 |

- 1日の提案上限：5件
- ポイント値は親が承認時に設定

---

## 3. ADHD対応の工夫

- **時間帯ブロック制**：「〇時に何をする」ではなく「朝のミッション」のようなブロック管理
- **1タスク1画面表示**：「今やること1つ」にフォーカスできるモード
- **タスクの細分化**：大きなタスクを小さなステップに分解して登録
- **段階的リマインダー**：15分前 → 5分前 → 時刻になった、と複数回通知
- **即時フィードバック**：完了ボタンを押した瞬間のアニメーションで報酬を即時に与える
- **ストリークの可視化**：連続日数を炎アイコンで表示。途切れても「リスタートバッジ」を用意

---

## 4. 通知種別

| 種別 | タイミング | 受取人 |
|---|---|---|
| reminder | 設定時刻の15分前・5分前 | 子ども |
| followup | 設定時刻の30分後（未完了時） | 子ども・親 |
| approval | 子どもが完了報告した直後 | 親 |
| proposal | 子どもが提案を送った直後 | 親 |
| result | 親が承認・却下した直後 | 子ども |
| summary | 就寝前（時刻設定可） | 親 |
| streak | 連続〇日達成時 | 子ども |

---

## 5. ゲーミフィケーション

### バッジ設計

| バッジ名 | 獲得条件 |
|---|---|
| はじめの一歩 | 初めてタスクを完了 |
| 3日連続！ | 3日連続でルーティン完了 |
| 朝のチャンピオン | 朝のミッションを7日連続完了 |
| パーフェクトデー | 1日のタスクを全て完了 |
| 100ポイント達成 | 累計100ポイント獲得 |
| はじめての提案 | 初めてタスクを提案・承認された |
| リスタート勇者 | ストリーク途切れ後に再び3日連続達成 |

### ご褒美交換
- 親がご褒美内容とポイントコストを設定
- 子どもがポイントを使って申請 → 親が承認
